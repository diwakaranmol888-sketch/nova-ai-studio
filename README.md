# NOVA AI — Local Business Growth Studio

A single-page, animated landing page + content studio that turns a product idea into Instagram captions, WhatsApp messages and product listings.

- **Demo mode (default):** JavaScript templates, works offline after load.
- **Local model mode (experimental):** loads an open-weight Qwen model in the browser via Transformers.js.

## Run locally
Just open `index.html` in a browser. (For local model mode, use a local server: `python -m http.server 8000`.)

## Deploy
Hosted with GitHub Pages — see the Actions workflow in `.github/workflows/pages.yml`.
